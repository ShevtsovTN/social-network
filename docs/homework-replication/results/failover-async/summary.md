# Эксперимент: авария мастера, режим async

| Параметр | Значение |
|---|---|
| Режим репликации | асинхронный |
| Задержка сети primary → реплики (netem) | 300ms |
| Нагрузка на запись | 8 VU на приложение (native и symfony), 40 с, kill на 15-й секунде |
| Новый мастер | replica1 (самая свежая реплика по pg_last_wal_receive_lsn) |
